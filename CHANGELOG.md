# Changelog

All notable changes to TH80 Open are documented here.

The project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-03

Initial public source baseline.

- Add the offline TH80 Studio desktop configurator and shared profile core.
- Add the `th80ctl` offline profile-management CLI.
- Add passive Linux sysfs/HID descriptor inspection tooling and offline protocol analysis utilities.
- Document hardware research, protocol evidence, compatibility limits, safety boundaries, and platform verification.
- Add cross-platform GitHub Actions repository verification.

Physical keyboard configuration, firmware updates, bootloader operations, and RGB writes are not supported by this release.
